# Basic calculator

Пет-проект, создан прежде всего для понимания синтаксиса языка и частично затрагивает ООП, обычный калькулятор, реализовано:
* Рассчет результата выражения на основе расставления приоритетов между (), *, /, +, -

## Возможности

- из строки в приоритетном порядке производитса рассчет результата выражения(приоритет - (), *, /, +, -)

## Установка

- git clone https://github.com/EloniTest/Basic-calculator
- cd repository
